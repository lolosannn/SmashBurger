# Fotos del menú

⚠️ **Las fotos actuales son placeholders de demo**, sacadas de repos públicos de GitHub
(no hay licencia clara para uso comercial). Sirven para ver el diseño funcionando, pero
**hay que reemplazarlas por fotos propias o compradas antes de lanzar el sitio de verdad.**

Subí acá estos archivos con estos nombres exactos (minúsculas, sin espacios) para que
`index.html` los tome automáticamente:

- `hero-tokyo.png` (o `.jpg`) — foto de portada (hero)
- `tokyo.jpg` — foto de la card "Tokyo" en el menú
- `denver.jpg`
- `sinaloa.jpg`
- `kiev.jpg`
- `miami.jpg`

Formato recomendado: JPG, PNG o WEBP, orientación horizontal o cuadrada, al menos 800px de
ancho. Por ahora `hero-tokyo` se muestra dentro de una card con marco (igual que las demás
fotos), así que funciona tanto con fondo transparente como con fondo de color/estudio.

Si más adelante conseguís una versión de `hero-tokyo` con el fondo realmente recortado
(transparente), avisá para cambiar el hero a un estilo "flotante" sin marco ni fondo.

Cómo subirlas desde GitHub (sin necesidad de git en la terminal):

1. Entrá al repo en `github.com/lolosannn/SmashBurger`, asegurate de estar parado en la
   rama `claude/burger-shop-web-design-exe4jr` (selector de rama arriba a la izquierda).
2. Andá a la carpeta `images/`.
3. Botón **Add file → Upload files**.
4. Arrastrá las 5 fotos, renombralas si hace falta a los nombres de arriba, y confirmá el
   commit directo sobre esa rama.
